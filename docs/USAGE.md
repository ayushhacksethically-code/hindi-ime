# Usage Guide

## Activating Hindi IME

1. Ensure Fcitx5 is running (`fcitx5 &`).
2. Switch input method to `hindi_ai` (default toggle is usually `Ctrl + Space` or `Super + Space`).

## Typing in Hinglish

Type phonetic Hinglish words as you naturally spell them:

- `namaste` → **नमस्ते**
- `aapka` → **आपका**
- `kya haal hai` → **क्या हाल है**
- `samasya` → **समस्या**
- `zindagi` → **ज़िंदगी**

## Single-Space Commit

The `hindi_ai` schema is configured with single-space commit:
- Typing a word and pressing `Space` immediately commits the top Devanagari candidate and inserts a single space.
- Number keys (`1` - `5`) can be pressed to pick alternative candidate suggestions.
